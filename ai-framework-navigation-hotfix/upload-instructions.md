# AI Framework navigation hotfix

This hotfix replaces one file in the `ai-framework-live` GitHub repository.

1. Open the `ai-framework-live` repository on GitHub.
2. Open `static`, then `js`.
3. Choose **Add file → Upload files**.
4. Upload the included `static/js/site-enhancements.js` file.
5. Confirm that GitHub shows `site-enhancements.js` as modified.
6. Commit with the message `Fix frozen top navigation`.
7. Wait for Netlify to finish deploying, then hard-refresh
   `https://ai-framework.io/`.

No other site files need to be removed or replaced.
